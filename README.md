# GTA VI launch-day Twitch forecast

A forecaster for the Grand Theft Auto VI release day's hourly Twitch concurrent viewers (hours 2–24, five quantiles each). The method learns the shape of a launch day from the 42 past launches shipped in the case file: each comparable's release-day curve is normalised by its own hour-1 print and taken in log space, then the target hour is forecast as hour-1 print times exp(kernel-weighted mean + z_tau * kernel-weighted SD of the comparables' log-ratios), with weights from a Gaussian kernel on log hour-1 print (bandwidth 1.0) times x5 for console-only launches like GTA VI, and a 0.9 spread calibration. A small hour-1 print means most of the world has yet to unlock, so the forecast grows steeply; a big one means the launch is already global and the day stays flat. On the four practice launches it scores a mean pinball loss of 0.201 on the log scale, against the house baseline's 0.387.
